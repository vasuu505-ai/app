Production-Ready Koyeb Endpoints

Integrate these live endpoints directly into your mobile app or external frontend.

GET /api/numbers/{number}/messages

Returns all OTP messages for a specific number with clean_otp, sender, app_id, etc.

GET /api/numbers

Returns all numbers with supported_apps array, blocked_apps, country, flag, status, and received_sms_count.

GET /api/apps

Returns catalog of popular apps with active country counts and availability status.

GET /api/otps/stream

Server-Sent Events (SSE) live stream of all incoming OTP messages in real-time.

POST /api/notifications/subscribe

Registers FCM device token for background phone push notifications on a specific number.
